حساب کالا – نسخه حرفه‌ای و نصب‌شونده روی آیفون

ویژگی‌ها:
- داشبورد موبایلی با عکس صاحب برنامه
- عکس شخصی در سربرگ و آیکن برنامه
- خرید، فروش، مشتری و طلب، مصارف
- سود ناخالص و سود خالص
- مدیریت موجودی کالا
- گزارش مالی
- پشتیبان‌گیری و بازیابی
- ذخیره اطلاعات داخل خود مرورگر (localStorage)
- PWA و قابل نصب روی صفحه اصلی آیفون

نکته: برای نصب روی آیفون، فایل‌ها باید روی GitHub Pages یا یک HTTPS hosting قرار داشته باشند؛ سپس در Safari گزینه Add to Home Screen را بزنید.
